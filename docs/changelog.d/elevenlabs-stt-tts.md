- **ElevenLabs STT (Scribe) and bot-layer TTS are a first-class dialect, not a platform domain.** Point `TRANSCRIPTION_SERVICE_URL` at `https://api.elevenlabs.io` (or set `TRANSCRIPTION_BACKEND=elevenlabs` behind a private proxy) and the bot, boot probe, Settings Test, and terminal dictation POST `/v1/speech-to-text` with `xi-api-key`. Bot speak can use the same key via `TTS_SERVICE_URL` / `TTS_VOICE_ID` (`pcm_24000` into the virtual mic). `POST /bots/.../speak` is still 404. See [Use ElevenLabs for STT and TTS](/how-to/elevenlabs).
